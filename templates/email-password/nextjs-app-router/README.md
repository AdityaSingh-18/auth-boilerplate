# Email & Password Authentication

A headless email and password authentication template for Next.js App Router.

## Included

- `core/` — Required authentication backend.
- `core/lib/auth.ts` — Authentication operations.
- `core/lib/auth-db.ts` — Database adapter interface.
- `core/api/auth/` — Authentication API routes.
- `optional-ui/` — Optional example UI.

## Setup

1. Copy the contents of this template into your Next.js project.
2. Configure the required environment variables when the full implementation is available.
3. Implement the database adapter for your database.
4. Connect your own UI to the authentication API.

> This is an initial template scaffold. Full authentication logic and database implementations will be added in Phase 5.
